# T97 — File notes lead with pitfalls and the test to run

**Branch:** `feat/edit-time-notes` · **Size:** S · **Rules:** [README](README.md)

## Goal
The note Claude Code loads when a file is opened answers "what can go wrong here, and how do I
test it" first; purpose and navigation come after.

## Facts
- `planRuleStubs` in `scripts/lib/rules.mjs` builds each note body from the module page:
  marker line, `Purpose:`, the first `Entry points:` bullet, the first `Pitfalls:` bullet,
  `Policies:`, `Decisions:`, `Full page:`, and a stale warning. `MAX_BODY = 10` lines,
  each clipped to `MAX_LINE`.
- `bullet(text, label)` returns only the single line `- <label>: …`; sub-bullets under it are
  lost, so a page with several pitfalls contributes one.
- Pages carry `- Tests: <paths>` and `- Run/test this part: <command names>` bullets
  (`skills/add-project/references/knowledge-contract.md`); notes ignore both today.
- `claude plugin eval` never loads `.claude/rules/`, so this cannot be shown with an eval; unit
  tests are the evidence. Say so in the PR.

## Owns
`scripts/lib/rules.mjs`, `tests/unit/rules.test.mjs`, one sentence in
`skills/add-project/references/knowledge-contract.md`.

## Steps
1. Extend `bullet` (or add a sibling) to also return up to 2 indented sub-bullets directly
   under the labelled bullet, skipping fenced code.
2. New body order: marker line; `Pitfalls:` (the bullet plus up to 2 sub-bullets, so at most
   3 pitfalls); `Test:` from the `Tests:` bullet; `Run:` from the `Run/test this part:`
   bullet; `Entry points:`; `Purpose:`; `Policies:`; `Decisions:`; `Full page:`; stale note.
   Missing parts are skipped, as today.
3. Raise `MAX_BODY` to 12. The stale warning and `Full page:` line must never be cut off: if
   the body is too long, drop from `Purpose:` upward first.
4. Keep the generated marker and the secret check exactly as they are.
5. Add one sentence to `knowledge-contract.md`: notes show pitfalls, the covering test and the
   run command first, so pages should keep those bullets short.

## Tests (`tests/unit/rules.test.mjs`)
- A page with a Pitfalls bullet and three sub-bullets yields the bullet plus two sub-bullets.
- `Test:` and `Run:` lines appear when the page has them, in the new order.
- A stale page with every section still ends with the `Full page:` and stale lines.
- A page with no Pitfalls/Tests/Run produces a valid note (no empty lines, no crash).
- Existing marker, frontmatter `paths:` and secret-skip tests still pass unchanged.
- Show the order and sub-bullet tests fail on the old code.

## Done when
All pass, every interpretation listed in the PR, and the PR states why there is no eval.
