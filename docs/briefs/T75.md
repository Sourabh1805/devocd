# T75 — Secret scanner coverage with a false-positive guard

**Branch:** `feat/secret-coverage` · **Size:** M · **Rules:** [README](README.md)

## Goal
Catch the common secret types without flagging ordinary code, hashes or placeholders.

## Facts
- `scanSecrets(text)` in `scripts/lib/secrets.mjs` returns `[{ line, kind }]`, never the value.
  It knows 4 patterns (AWS key, GitHub token, Slack token, private-key block) plus one
  keyword-and-entropy rule.
- Callers **skip or drop** what matches (`inventory.mjs`, `knowledge.mjs`, `rules.mjs`,
  `projects.mjs`, `artifacts.mjs`) or **reject or report** it (`check.mjs`, `claims.mjs`,
  `context-store.mjs`, `content-check.mjs`). A miss leaks a secret into knowledge; a false
  positive silently drops a real source file from knowledge.

## Owns
`scripts/lib/secrets.mjs`, `tests/unit/secrets.test.mjs`, one sentence in `SECURITY.md`.

## Steps
1. Add to `FIXED`, each with this kind name:
   `gitlab-token` (`glpat-` + 20+), `openai-key` (`sk-`/`sk-proj-` + 40+, not `sk-ant-`),
   `anthropic-key` (`sk-ant-`), `google-api-key` (`AIza` + 35), `stripe-key` (`sk_live_`,
   `rk_live_`; never `sk_test_`), `slack-webhook` (`hooks.slack.com/services/…`),
   `sendgrid-key` (`SG.` + two dotted segments), `twilio-key` (`SK` + 32 hex), `npm-token`
   (`npm_` + 36), `pypi-token` (`pypi-` + long value), `azure-storage-key` (`AccountKey=`),
   `connection-string-password` (`Password=`/`pwd=` with a non-empty value in a `k=v;` string),
   `jwt` (three base64url segments, first two starting `eyJ`), `url-credentials`
   (`scheme://user:password@host`), `auth-header` (`Authorization: Basic|Bearer` + 20+ chars),
   `pgp-private-key` (`-----BEGIN PGP PRIVATE KEY BLOCK-----`), `docker-auth`
   (`"auth": "<base64>"` inside `auths`). Keep the existing four and the generic rule.
2. False-positive guard, applied before reporting: never flag a `sha256:<64 hex>` line, a bare
   40- or 64-hex hash, a UUID, a value of one repeated character, or placeholders (`xxx…`,
   `<token>`, `${VAR}`, `%VAR%`, `example`, `changeme`, `your-…-here`, `dummy`, `fake`, `test`).
   One small named list.
3. One scanner only; the return shape is unchanged.
4. Measure: run `node scripts/devocd.mjs knowledge-inventory .` on this repository and on
   `evals/_fixture/knowledge` before and after. Put every newly skipped file (with its kind) in
   the PR. A real file newly skipped means the guard is wrong: fix the guard.
5. Docs: list the detected kinds in one sentence in `SECURITY.md`; delete the four-patterns
   line from Traps in `docs/repo-memory.md`.

## Tests (`tests/unit/secrets.test.mjs`, table tests)
- One true positive per new kind (fake values of the right shape).
- True negatives: `sha256:` evidence line, git SHA, UUID, every placeholder, `sk_test_…`,
  `const token = getToken()`, a long base64 `data:` URI image.
- No output ever contains the matched value.
- Each new pattern's test fails with that pattern removed (say how you checked).

## Done when
All pass, the inventory before/after is in the PR, every interpretation listed.
