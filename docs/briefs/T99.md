# T99 — Completion helpers report the check result they were gated on

**Branch:** `feat/completion-evidence` · **Size:** S · **Rules:** [README](README.md)

## Goal
When knowledge is marked current, the helper output carries the `check` result that allowed it,
so a skill can show evidence instead of just saying "done".

## Facts
- The gate already exists in code: `baselineRefresh` and `completeRefresh` in
  `scripts/lib/refresh.mjs` throw `INVALID_DRAFT` ("Project checks failed; knowledge is not
  marked current.") when `checkTree(root)` has any error-severity issue.
- On success they return the `writeKnowledge` result plus `current: true` (or
  `current: false` with a `baseline` reason). The check result is computed and thrown away.
- The CLI prints that object as JSON (`refresh-baseline`, `refresh-complete` in
  `scripts/devocd.mjs`). The add-project skill already says "Report files, checks, graphs".
- `skills/add-project/SKILL.md` and `skills/setup/SKILL.md` are at their 900-token limit:
  **do not edit any SKILL.md.** The enforcement lives in Node.

## Owns
`scripts/lib/refresh.mjs` (`baselineRefresh`, `completeRefresh` only),
`tests/unit/refresh.test.mjs` (or `refresh-impact.test.mjs` if the tests fit there better).

## Steps
1. Run `checkTree(root)` once per call and reuse it for both the gate and the report.
2. Add `checks: { errors, warnings, information }` (counts) to every returned object, success
   or `current: false`. On the error path keep throwing as today, and include the counts in the
   error message (`… (2 errors, 5 warnings)`).
3. Never include issue text or file content in the result: counts only.

## Tests
- Success: `checks` is present with the right counts for a fixture with known warnings.
- `current: false` paths (partial inventory, fingerprint mismatch, skipped pages) also carry
  `checks`.
- An error-severity issue still blocks, and the message carries the counts.
- `checkTree` runs once per call (spy or count via a fixture), not twice.
- Show the new tests fail on the old code.

## Done when
All pass, no SKILL.md changed, every interpretation listed in the PR.
