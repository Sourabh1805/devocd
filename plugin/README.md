# DevOCD

DevOCD is a skills-only Claude Code plugin. It sets up company-wide
standards that Claude Code loads from a parent folder, and reviews pull
requests against those standards. It runs no hooks and no servers, makes
no git changes by default, and sends nothing anywhere. Skills are still
being built, so this version ships none yet.

## Install

```text
/plugin marketplace add Sourabh1805/devocd
/plugin install devocd@devocd
```
